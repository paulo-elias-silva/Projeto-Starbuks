# **Projeto-Starbuks**

## Site Starbuks

Este repositório contém o projeto de recriação da interface do site da Starbucks, desenvolvido exclusivamente com HTML5 e CSS3. O objetivo principal deste projeto é aprimorar minhas habilidades em desenvolvimento front-end, focando na construção de layouts responsivos e na aplicação de técnicas avançadas de CSS.

Ao analisar o código, se sinta a vontade para dar alguma sugestão.
